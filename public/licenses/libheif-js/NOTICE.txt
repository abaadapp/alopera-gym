برنامج مفتوح المصدر مستخدم في لوحة النادي — Open-source software used in the club panel
=====================================================================================

يستخدم المتصفح هذه المكتبة لعرض صور الآيفون (HEIC/HEIF) في المتصفحات التي لا تقرؤها بنفسها. تعمل داخل
متصفح المستخدم فقط، على الصورة التي اختارها، ولا تغيّر الصورة الأصلية. وهي مرخّصة برخصة
GNU LGPL الإصدار 3؛ نصها ونص GNU GPL الإصدار 3 في LICENSE.txt بجانب هذا الملف.

The browser uses this library to show iPhone photos (HEIC/HEIF) in browsers that cannot read them. It runs only in the
user's browser, on the file they picked, and never changes the original. It is covered by the GNU Lesser General Public
License version 3; that licence and the GNU General Public License version 3 it builds on are in LICENSE.txt beside
this file.

Replacing it
------------
The library is a separate file that the application loads at run time through its documented interface
(HeifDecoder().decode → image.display). An interface-compatible build of libheif-js can be put in its place: build this
application with it (npm install, npm run build), or serve another build at the same address. Nothing in this
application's terms forbids changing the library or reverse engineering it to debug such a change.
