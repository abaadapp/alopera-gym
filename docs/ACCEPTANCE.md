# اختبارات القبول

حسب جدول «اختبارات القبول» في المواصفات، مع ما تم آليًا وما يتبقى يدويًا بعد النشر.

| المتطلب | طريقة التحقق في المواصفة | ما تم | ما يتبقى |
|---|---|---|---|
| الصلاحيات حسب الدور | مراجعة المصفوفة واختبار كل دور | [PERMISSIONS.md](PERMISSIONS.md) مولّدة من الكود؛ `PermissionsTest` (33 حالة) | مراجعة المصفوفة مع إدارة النادي وتعديل الأدوار حسب رغبتها |
| HTTPS | فحص الشهادة على الدومين | إعداد Nginx + HSTS + كوكيز آمنة | بعد النشر: `curl -I https://<domain>` و SSL Labs |
| سجل العمليات | عرضه من لوحة الإدارة | «الإعدادات ← سجل العمليات» + `ExportsAuditSecurityTest` | — |
| النسخ الاحتياطي | استرجاع تجريبي قبل الإطلاق | `BackupRestoreTest` (استعادة نادٍ كاملة)، `restore-drill.sh` جُرّب محليًا | تشغيل الـ drill على نسخة الإنتاج قبل الإطلاق |
| تصدير البيانات | تنفيذ تصدير تجريبي | تصدير CSV/Excel للمشتركات والعضويات والمالية — مختبر آليًا | تصدير تجريبي من الإنتاج وفتحه في Excel |
| الموقع والدفع | نجاح اشتراك تجريبي كامل | التسجيل أونلاين ← فاتورة ← Webhook موقّع ← تفعيل (اختبارات `SiteAndPortalTest` و`PaymobPaymentTest`) | اشتراك حقيقي بوضع اختبار Paymob بعد إدخال مفاتيح النادي |

## سيناريو قبول يدوي مقترح (بعد النشر)

1. **التثبيت**: `php artisan gym:install` على الخادم ← دخول صاحب النشاط.
2. **الإعداد**: الشعار والألوان، الفروع، المستخدمات لكل دور، الباقات، البرامج، المدربات وأوقاتهن، الجدول الأسبوعي.
3. **الاستقبال**: تسجيل مشتركة ← بيع باقة ← تحصيل نقدي ← التحقق من الدخول بالـ QR ← حجز حصة.
4. **التحويل البنكي**: تسجيل تحويل بإثبات ← العضوية تبقى بانتظار الدفع ← المالية تؤكد ← العضوية نشطة.
5. **الموقع**: اشتراك أونلاين بدفع Paymob تجريبي ← ظهور المشتركة والعضوية فورًا في اللوحة.
6. **البوابة**: دخول المشتركة ← حجز وإلغاء حصة ← تجديد.
7. **واتساب**: تفعيل الربط ← اعتماد قالب الترحيب ← تسجيل مشتركة ← وصول الرسالة وظهورها «وصلت/قُرئت».
8. **التجميد والانتهاء**: تجميد ← رفض الدخول ← استئناف ← تمديد تاريخ الانتهاء.
9. **التقارير**: مقارنة الشهر الحالي بالسابق، تصدير Excel.
10. **الأدوار**: الدخول بكل دور والتأكد من الشاشات المسموحة/الممنوعة.
11. **النسخ**: إنشاء نسخة ← تعديل بيانات ← استعادة ← التحقق.
