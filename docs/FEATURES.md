## 8 · خارج النطاق الحالي

⛔ كاميرات المراقبة و VMS · الربط البنكي المباشر والمطابقة الآلية · التحليلات المتقدمة والذكاء الاصطناعي ·
تطبيق جوال وبرامج الولاء · فروع وأجهزة إضافية · نقل البيانات من النظام القديم.
لم يُنفّذ أي منها؛ البنية (وحدات مستقلة، أحداث نطاق، API أجهزة، تصدير) تسمح بإضافتها.
